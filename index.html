prasithbasky/eigen_mat

Refactoring legacy numerical dependencies to decouple the solver path from the MUMPS library. This makes the architecture more modular and allows alternate high-performance sparse-matrix paths. I am also developing eigenvalue and eigenvector solver routines for highly non-linear finite element computations.

FortranLAPACKARPACKSparse matrices
Technical details: LAPACK and ARPACK in Fortran

LAPACK provides dense linear algebra routines, used for smaller eigenproblems and the dense blocks inside iterative methods.

ARPACK uses implicitly restarted Arnoldi/Lanczos iterations to find a few eigenvalues and eigenvectors of large sparse systems without a full decomposition.

Non-linear implicit FE analyses solve large sparse systems again and again. Separating the solver path from a single library makes it possible to test other sparse paths and keep the eigen routines reusable. Fortran matches the existing OpenRadioss code base.
